# Agentic_AI_Langgraph

Learn LangGraph by working through practical examples. Each notebook covers a key workflow pattern you'll use in real AI applications.

## The Notebooks

1. **BMI State Demo** — Basic example how state flows through the workflows
2. **Sequential Q&A** — Chain steps together: Question → Process → Answer
3. **Prompt Chaining** — Break big problems into smaller prompt-based steps
4. **Parallel Workflows** — Run multiple tasks at the same time
5. **Essay Evaluation** — Real-world example: evaluate essays in parallel
6. **Conditional Routing** — Make decisions: "if this, do that"
7. **Review & Reply** — Conditional logic in action
8. **Iterative Loops** — Repeat until you get it right



Activate your environment and run Jupyter:

```bash
myenv\Scripts\activate
pip install -r ../requirement.txt
jupyter notebook
```
